# Sticker.pi Mainnet — Release Candidate Notes

This repository was forked from the reviewed Testnet release candidate and converted to a strictly isolated Mainnet configuration.

The app uses Pi SDK authentication, verifies identity and payments server-side, and grants a purchased pack only after the payment reports the correct user, direction, amount, memo, product metadata, `Pi Network` network and verified completion status.

Current candidate: `v1.0.0-rc.1`. Mainnet submission is blocked until the deployment, dedicated credentials, isolated storage and one real low-value transaction are verified.
